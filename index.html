S-RIM 가치평가 시뮬레이터

FnGuide 자동 채우기 지원 · Netlify Functions 버전

프론트는 순수 HTML/CSS/JS, 자동 채우기는 Netlify Functions로 처리하는 버전입니다. FnGuide URL 또는 종목코드를 넣으면 연결재무제표 기준 값을 자동으로 읽어와서 S-RIM 3단계 시나리오를 계산합니다.

S-RIM 공식
ω < 1.0 : V = BV + BV × (ROE − ke) × ω / (1 + ke − ω)
ω = 1.0 : V = BV + BV × (ROE − ke) / ke

입력값

Functions API 연동
FnGuide 자동 채우기

FnGuide URL 또는 6자리 종목코드를 입력한 뒤 자동 채우기를 누르면, Netlify Function이 FnGuide 페이지를 읽어서 회사명, 연결 기준 지배주주지분, ROE, 발행주식수를 채웁니다.
